API de Wali

Conecta tus otros sistemas con Wali. Lee las conversaciones y los contactos de tu CRM, haz acciones como asignar en lote o cambiar la etapa, y arma tus automatizaciones: flujos, agentes de IA, reglas, etiquetas y etapas.

Todas las llamadas van a esta dirección, con tu clave en la cabecera Authorization.

https://walicrm.com/crm/api/v1
curl https://walicrm.com/crm/api/v1/yo \
  -H "Authorization: Bearer wali_live_TU_CLAVE"

Claves y permisos

Un administrador crea las claves en Ajustes del CRM › API. La clave se muestra completa una sola vez. Guárdala en el sistema que la va a usar.

  • Cada clave ve solo su espacio de trabajo y nunca toca pagos ni la cuenta. De los ajustes, arma flujos, agentes de IA, reglas automáticas, etiquetas, etapas y el horario de atención.
  • Solo lectura. Lee todo lo de esta página que empieza con GET.
  • Lectura y acciones. Además asigna, cambia la etapa, pone etiquetas, finaliza, crea o edita contactos, y crea, edita, enciende o borra flujos, agentes de IA, reglas automáticas, etiquetas y etapas. También cambia el horario de atención.
  • Las acciones se hacen en nombre del administrador que creó la clave, con las mismas reglas que en la pantalla, y quedan registradas.
  • La clave deja de funcionar si la revocas, si vence o si quien la creó ya no es administrador del espacio.
Nunca pongas la clave en una página web ni en una app que se instale en el celular de otra persona. Úsala solo desde tu servidor.

Límites y errores

Hasta 120 llamadas por minuto por clave. Cada respuesta trae las cabeceras RateLimit-Remaining y RateLimit-Reset. Si pasas el límite, la respuesta es 429. Espera los segundos que indica Retry-After.

CódigoQué pasó
400Faltan datos o tienen otra forma. El campo detalle dice cuál.
401La clave no es válida, venció o fue revocada.
403La clave es de solo lectura, o el plan del espacio no está activo (queda en solo lectura).
404Eso no existe en este espacio.
409Alguien cambió lo mismo en el CRM al mismo tiempo. Vuelve a intentarlo.
429Pasaste el límite de llamadas por minuto.

Los errores llegan como { "error": "…" } y las respuestas buenas como { "data": … }.

Páginas

Las listas devuelven hasta 50 elementos (máximo 100 con limite). Si hay más, la respuesta trae siguiente. Pásalo como cursor para pedir la página que sigue.

GET /conversaciones?limite=100
GET /conversaciones?limite=100&cursor=4521

Conversaciones

GET/conversacionesLectura

Filtros: estado (abiertas, pendientes o finalizadas), asignado (id del miembro, o nadie), equipo, etapa, desde y hasta (fechas ISO, por última actividad).

curl "https://walicrm.com/crm/api/v1/conversaciones?estado=abiertas&asignado=nadie" \
  -H "Authorization: Bearer wali_live_TU_CLAVE"
{ "data": [ { "id": 4521, "estado": "abiertas", "canal": "wa", "asignadoId": null, "equipo": "Ventas",
    "contacto": { "id": 812, "nombre": "Laura Gómez", "telefono": "+573000000000", "etapa": "Caliente", "etiquetas": ["Referido"] },
    "ultimoMensaje": "2026-11-11T15:02:11.000Z", "creada": "2026-11-10T21:40:00.000Z" } ],
  "siguiente": 4519 }
GET/conversaciones/:idLectura
GET/conversaciones/:id/mensajesLectura

Del más nuevo al más viejo. Cada mensaje trae tipo (in, out, note…), texto, archivo si tiene, autorId y en.

PATCH/conversaciones/:idAcciones

Manda solo lo que cambias: etapa, etiquetas (agregar y quitar), estado con su motivo, miembroId o equipo.

curl -X PATCH https://walicrm.com/crm/api/v1/conversaciones/4521 \
  -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json" \
  -d '{ "etapa": "Pagado", "etiquetas": { "agregar": ["Cliente frecuente"] } }'

Asignar en lote

POST/conversaciones/asignarAcciones

Hasta 100 conversaciones por llamada. Manda miembroId (o null para dejarlas sin asignar), equipo, o los dos. Cada una pasa por las mismas reglas que en la pantalla. Las que no se pueden asignar vuelven en errores con su motivo.

curl -X POST https://walicrm.com/crm/api/v1/conversaciones/asignar \
  -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json" \
  -d '{ "conversaciones": [4521, 4519, 4510], "miembroId": "ID_DEL_MIEMBRO" }'
{ "data": { "asignadas": [4521, 4519], "errores": [ { "id": 4510, "error": "…" } ] } }

Contactos

GET/contactosLectura

Filtros: q (nombre, teléfono o correo), etapa y etiqueta.

GET/contactos/:idLectura

Campos: nombre, telefono (con el indicativo del país), correo, etapa y etiquetas. Para crear hace falta teléfono o correo.

Equipos, miembros y etapas

Para saber qué valores usar en los filtros y en las acciones.

RutaQué trae
GET /miembrosLas personas del espacio, con su id para asignar.
GET /equiposLos equipos y los ids de sus miembros.
GET /etapasLas etapas del embudo, cada una con su color y su equipo.
POST /etapasCrea una etapa: nombre (obligatorio), color (opcional, como #2563eb) y equipo (opcional, por defecto Ventas). Queda al final de las etapas de ese equipo. Responde 201 con la etapa; 409 si el equipo ya tiene una con ese nombre.
PATCH /etapas/:nombreCambia el color de una etapa. Si la etapa no es del equipo inicial, manda también equipo.
DELETE /etapas/:nombreBorra una etapa (con ?equipo= si no es del equipo inicial). Responde 409 si hay contactos en ella: muévelos primero.
GET /etiquetasLas etiquetas del espacio.
POST /etiquetasCrea una etiqueta: nombre, y opcionales color y equipo (sin equipo, es para todos).
DELETE /etiquetas/:nombreBorra una etiqueta.
GET /lineasLas líneas de WhatsApp conectadas.
GET /yoEl espacio, el nombre y el permiso de la clave.

Flujos

Los flujos contestan solos el primer mensaje: saludan, preguntan, ofrecen botones y pasan la conversación a un equipo o a una persona. Todo flujo termina en una persona.

GET/flujosLectura
GET/flujos/:idLectura

El flujo completo, con sus pasos.

POST/flujosAcciones
PATCH/flujos/:idAcciones
PUT/flujos/:idAcciones
DELETE/flujos/:idAcciones

PATCH cambia solo lo que mandas; por ejemplo, { "encendido": false } lo apaga. PUT lo reemplaza entero. Un flujo nuevo queda apagado si no mandas encendido.

CampoQué es
nombreObligatorio al crear. No se repite.
cuandoprimer-mensaje (por defecto), fuera-de-horario o anuncio.
canalesDónde corre: wa, ig, fb, tg, tt, web, mail.
equiposSolo en conversaciones de esos equipos. null o vacío: todos.
saltarConocidosNo corre con quien ya escribió antes (por defecto true).
esperaMinutosSi el cliente no responde en ese tiempo, pasa a una persona (de 1 a 1440).
pasosDe 1 a 30, en orden. Mira la tabla de abajo.
PasoCampos
mensajetexto. Puedes usar {{nombre}} si ya lo preguntaste.
preguntatexto, guardarEn (nombre, correo, ciudad o producto), validar (nombre-y-apellido, texto-libre, correo o numero) y reintento (lo que dice si la respuesta no sirve).
botonestexto y opciones (hasta 6, de máximo 20 caracteres; en WhatsApp, con más de 3 opciones salen como lista con el botón «Ver opciones»). Con ponerEtiqueta: true, la opción elegida queda como etiqueta.
etiquetaetiqueta: una que ya exista (créala con POST /etiquetas).
asignarequipo (reparto automático en ese equipo) o miembroId. Termina el flujo, así que va de último. Sin este paso, al terminar pasa al equipo de la conversación.
avanzadoPasos que solo se arman en el CRM (la pregunta que reparte por área). Llegan así en GET /flujos/:id; para conservarlos, mándalos igual.
curl -X POST https://walicrm.com/crm/api/v1/flujos \
  -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json" \
  -d '{ "nombre": "Citas", "cuando": "primer-mensaje", "canales": ["wa"], "encendido": true,
        "pasos": [
          { "tipo": "mensaje", "texto": "¡Hola! Gracias por escribirnos." },
          { "tipo": "pregunta", "texto": "¿Cuál es tu nombre y apellido?", "guardarEn": "nombre", "validar": "nombre-y-apellido", "reintento": "¿Me regalas también tu apellido?" },
          { "tipo": "botones", "texto": "¿Qué necesitas, {{nombre}}?", "opciones": ["Agendar cita", "Precios", "Otra cosa"], "ponerEtiqueta": true },
          { "tipo": "asignar", "equipo": "Ventas" } ] }'

Agentes de IA

Los agentes contestan con IA por los canales que elijas y pasan la conversación a una persona cuando hace falta. Para que contesten, el espacio necesita el motor de IA conectado en Ajustes del CRM › Integraciones.

GET/agentesLectura
GET/agentes/:idLectura
POST/agentesAcciones
PATCH/agentes/:idAcciones
DELETE/agentes/:idAcciones

Para crear, manda plantilla: recep (recepcionista), ventas, soporte o cero. Arranca con lo mismo que esa plantilla en el CRM y cambias lo que mandes. Queda apagado si no mandas encendido. PATCH cambia solo lo que mandas.

CampoQué es
nombre, presentacionCómo se llama y cómo se presenta.
queHaceSus instrucciones: qué hace, en una línea por tarea.
contexto, criterios, adicionalesLo que debe saber de la empresa, cómo decide y otras indicaciones.
tono, largoRespuestas, emojis, idiomaCómo escribe. largoRespuestas: cortas o medianas. idioma: Español, Inglés, Portugués o Francés.
canales, cuandoAtiendeDónde y cuándo contesta. cuandoAtiende: siempre, fuera-de-horario o en-horario.
pasaSiempreA, temasEl equipo al que pasa y, por tema, a qué otro equipo sugiere pasar: [{ "tema": "…", "equipo": "…" }].
pasaAPersonaCuándo pasa a una persona: listo, persona, molesto, mensajes y enlace (true o false), y mensajesAntesDePasar.
accionesLo que puede hacer: datos, equipo, etapa, nota, finalizar (true o false).
recopilarLos datos que pide: nombre, correo o la clave de un campo del contacto.
consultasLo que consulta en tus integraciones conectadas, como gcal.horarios, shopify.pedidos o hotmart.compras.
encendidoPara encenderlo, el espacio necesita un canal conectado y el agente, un canal en canales.

Los documentos de conocimiento se suben en el CRM, en la pestaña Conocimiento del agente.

curl -X POST https://walicrm.com/crm/api/v1/agentes \
  -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json" \
  -d '{ "plantilla": "ventas", "nombre": "Sofía", "canales": ["wa", "ig"],
        "contexto": "Somos un centro psicopedagógico en Bogotá…", "consultas": ["gcal.horarios"] }'

Reglas automáticas

«Cuando pasa esto, si se cumple esto, haz esto». Se identifican por su nombre, que no se repite.

GET/reglasLectura
POST/reglasAcciones
PATCH/reglas/:nombreAcciones
DELETE/reglas/:nombreAcciones
CampoValores
cuandomensaje-nuevo, se-asigna, cambia-etapa, pago-confirmado, 48-horas-sin-respuesta o se-finaliza.
condicionesLista de { "tipo", "valor" }: canal (wa, ig…), linea (id de GET /lineas), etapa, etiqueta; y sin valor: fuera-de-horario, anuncio, a-cuotas, sin-asesor.
accionesDe 1 a 10: asignar-por-turnos y pasar-al-equipo (equipo), asignar-a (id del miembro), cambiar-etapa, agregar-etiqueta, quitar-etiqueta, enviar-plantilla (nombre), enviar-respuesta-rapida (título); y sin valor: crear-recordatorio, avisar-al-lider, dejar-resumen, agente-ia-responde.
encendidaUna regla nueva queda apagada si no lo mandas.
curl -X POST https://walicrm.com/crm/api/v1/reglas \
  -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json" \
  -d '{ "nombre": "Leads de anuncio a Ventas", "cuando": "mensaje-nuevo", "encendida": true,
        "condiciones": [ { "tipo": "anuncio" } ],
        "acciones": [ { "tipo": "asignar-por-turnos", "valor": "Ventas" }, { "tipo": "agregar-etiqueta", "valor": "Anuncio" } ] }'

Horario de atención

El mismo de Ajustes del CRM › Horario de atención. Son los turnos con sus días, horas, almuerzo y las personas que los trabajan, más los festivos y el mensaje que le llega al cliente cuando escribe fuera de horario. El horario de la empresa se arma solo con los turnos, desde la primera hora hasta la última de cada día. De ese horario dependen el aviso fuera de horario, el agente de IA y el chat de la web. Solo lo cambia una clave creada por un administrador o un líder.

GET/horarioLectura
{ "data": { "turnos": [ { "id": "t1", "nombre": "Mañana", "color": "#3B82F6", "dias": [ { "dia": "lunes", "desde": "7:00", "hasta": "15:00", "almuerzo": { "desde": "12:00", "hasta": "13:00" } } ], "personas": ["usr_1"] } ],
  "horarioEmpresa": [ { "dia": "Lunes", "abierto": true, "desde": "7:00", "hasta": "15:00" } ],
  "festivosComoDomingo": true, "mensajeFueraDeHorario": "Estamos fuera de horario…", "dentroDeHorarioAhora": true } }
PATCH/horarioAcciones

Manda solo lo que cambia, ya sea turnos (la lista completa, que reemplaza la de hoy), festivosComoDomingo o mensajeFueraDeHorario. Los días van como lunes, martes, miercoles, jueves, viernes, sabado o domingo, y las horas como 7:00 o 18:30. Las personas son los id de GET /miembros. Para conservar el color de un turno, manda su id. Si alguien cambia el horario en el CRM en ese momento, la respuesta es 409. Vuelve a intentarlo.

curl -X PATCH https://walicrm.com/crm/api/v1/horario   -H "Authorization: Bearer wali_live_TU_CLAVE" -H "Content-Type: application/json"   -d '{ "mensajeFueraDeHorario": "Hoy atendemos hasta las 4 p. m." }'

Webhooks

Wali le avisa a tu sistema cuando pasa algo en tu espacio, sin que tengas que preguntar. Un administrador crea el webhook en Ajustes del CRM › API con la dirección de tu sistema (https) y los eventos que quieres recibir.

EventoCuándo llega
mensaje.recibidoUn cliente escribió.
conversacion.asignadaLa conversación cambió de persona o de equipo. Trae cómo estaba antes.
conversacion.finalizadaAlguien finalizó la conversación.
conversacion.etapaEl contacto cambió de etapa del embudo.
contacto.creadoEntró un contacto nuevo, por un canal o creado a mano.

Cada aviso llega por POST con este cuerpo. El id sirve para no procesar dos veces el mismo aviso.

{ "id": "5f1c…", "evento": "conversacion.asignada", "creado": "2026-11-11T15:02:11.000Z", "espacio": "…",
  "data": { "conversacion": { "id": 4521, "asignadoId": "…", "equipo": "Ventas", "estado": "abiertas", "etapa": "Caliente", "contactoId": 812 },
            "antes": { "asignadoId": null, "equipo": "Ventas" } } }

Responde con un código 2xx en menos de 10 segundos. Si no, Wali lo reintenta a 1, 5, 30, 120 y 360 minutos. Tras 20 fallas seguidas el webhook se pausa y se reactiva desde Ajustes del CRM › API.

Comprueba que viene de Wali. Cada aviso trae la cabecera Wali-Firma con la hora (t) y la firma (v1): HMAC-SHA256 de t.cuerpo con el secreto del webhook, que se muestra una sola vez al crearlo.

// Node.js
const [t, v1] = req.headers['wali-firma'].split(',').map(p => p.split('=')[1])
const esperada = crypto.createHmac('sha256', SECRETO).update(t + '.' + cuerpoCrudo).digest('hex')
const valida = crypto.timingSafeEqual(Buffer.from(v1), Buffer.from(esperada)) && Math.abs(Date.now() / 1000 - Number(t)) < 300
